# NutriLogic - 나만의 스마트 식단 코치

> 23101290 박기현 · 객체지향프로그래밍2 "AI를 활용한 나만의 프로그램 만들기" 과제

**배포 주소: https://bkbk4747.github.io/NutriLogic/**

먹은 음식을 기록하면, 내 신체 정보로 계산한 하루 목표와 비교해서 칼로리·탄수화물·단백질·지방이 얼마나 채워졌는지 보여 주는 웹 앱입니다.
PC와 스마트폰 브라우저에서 설치 없이 바로 사용할 수 있습니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 내 프로필 | 성별·나이(19~100세)·키·체중·운동 횟수·목표(감량/유지/증량) 입력 → 기초대사량(BMR), 하루 소비 열량(TDEE), 목표 칼로리·탄단지 계산 |
| 식단 기록 | 음식 88개 중 검색 → 섭취량(g) 입력(빈칸이면 1회 제공량) → 아침/점심/저녁/간식 끼니별 기록, 수정·삭제·되돌리기 |
| 직접 입력 | 목록에 없는 음식(외식·프랜차이즈 등)이나 영양 수치가 다른 음식은 이름·kcal·탄단지를 직접 입력 |
| 음식 데이터 추가 | 자주 먹는 음식을 100g 기준으로 내 음식 목록에 추가 |
| ☆ 즐겨찾기 | 음식 옆 별 버튼으로 즐겨찾기 지정(직접 입력한 음식 포함), 한 번에 기록 |
| 오늘 분석 | 칼로리 링, 탄단지 달성률, 부족/초과량, 최근 7일 그래프 |
| 다음 식사 추천 | 오늘 부족한 영양소를 채워 줄 음식 추천 (한 끼가 목표의 35%를 넘지 않게) |
| 지난 기록 | 최근 30일 그래프와 통계, 지난 날짜 기록 수정 |
| JSON 백업/복원 | 기록 전체를 파일로 내려받고, 다른 기기·브라우저에서 불러오기 |

## 사용 방법

1. 배포 주소에 접속합니다. 처음 접속하면 프로필 입력 화면이 나옵니다.
2. 프로필을 저장하면 하루 목표 칼로리와 탄단지가 계산됩니다.
3. **식단 기록** 탭에서 음식을 검색해 섭취량을 입력하고 기록합니다. 없는 음식은 **직접 입력**을 사용합니다.
4. **오늘** 탭에서 목표 대비 섭취량과 다음 식사 추천을 확인합니다.
5. **지난 기록** 탭에서 30일 동안의 변화를 봅니다.

## 데이터 저장 방식 (중요)

- 프로필과 식단 기록은 **브라우저의 localStorage**에 저장됩니다. 서버나 데이터베이스는 사용하지 않습니다.
- 그래서 **기기나 브라우저가 바뀌면 기록이 공유되지 않습니다.** (PC Chrome에서 쓴 기록은 휴대폰에서 보이지 않음)
- 다른 기기로 옮기려면 **내 프로필 → JSON 백업**으로 파일을 받은 뒤, 새 기기에서 **JSON 복원**으로 불러오면 됩니다.
- 브라우저의 "인터넷 사용 기록 삭제(사이트 데이터)"를 하면 기록도 지워지므로, 중요한 기록은 백업해 두는 것을 권장합니다.

## 1주차 C++ 프로그램과의 관계

1주차에 Visual Studio C++ 콘솔 프로그램으로 만든 NutriLogic을, 2주차에 같은 구조로 HTML/CSS/JavaScript 웹 버전으로 옮겼습니다.

| C++ (1주차) | 웹 (2주차) |
|---|---|
| `Nutrition`, `Consumable` → `FoodItem`, `UserProfile`, `DailyLog`, `FoodDatabase` 클래스 | `js/models.js`에 같은 이름의 JavaScript 클래스 |
| `main.cpp` 콘솔 메뉴 | `js/app.js` 화면 탭과 버튼 |
| `foods.csv` (음식 88개) | `js/foods.js` (같은 값) |
| `profile.txt`, 날짜별 기록 파일 | 브라우저 localStorage |

BMR·TDEE·목표 탄단지 계산식과 음식 데이터는 C++ 버전과 같고, 웹에서는 끼니 구분, 기록 수정, 즐겨찾기, 30일 기록, 다음 식사 추천, JSON 백업 기능을 추가했습니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 구조 (탭 5개: 오늘 / 식단 기록 / 즐겨찾기 / 지난 기록 / 내 프로필) |
| `style.css` | 디자인 (스마트폰·태블릿 화면 대응) |
| `js/foods.js` | 음식 88개 데이터 (100g 기준) |
| `js/models.js` | C++ 클래스를 옮긴 모델과 계산·추천 함수 |
| `js/app.js` | 화면 그리기와 버튼 동작 |

빌드 도구 없이 순수 HTML/CSS/JavaScript로 만들었으며, GitHub Pages(main 브랜치 루트)로 배포했습니다.
